Грамматика (문법)

🎯 이에요 / 예요 (быть / являться)

Правило 1: Если слово заканчивается на согласную → + 이에요

학생 + 이에요 = 학생이에요 (я студент)
의사 + 이에요 = 의사예요? (он врач?)

Правило 2: Если слово заканчивается на гласную → + 예요

가수 + 예요 = 가수예요 (я певец)
의사 + 예요 = 의사예요 (он врач)
🎯 은 / 는 (частицы темы)

Правило 1: Если слово заканчивается на согласную → + 은

학생 + 은 = 학생은 (что касается студента) 학생은 가수예요

Правило 2: Если слово заканчивается на гласную → + 는

가수 + 는 = 가수는 (что касается певца) 가수는 학생이에요

📝 Примеры:

저는 학생이에요
Я студент
소라는 가수예요
Сора — певица
민호는 의사예요
Минхо — врач
저는 러시아 사람이에요
Я из России
