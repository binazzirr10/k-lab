2. Моя страна

Выбери карточку — собери свою первую мини‑визитку.

🇰🇿
MY K‑LAB PASSPORT저는 카자흐스탄 사람이에요.

3. Два важных ответа

Теперь ты умеешь утверждать и отрицать.

이에요
아니에요

이에요 — «являюсь»: 카자흐스탄 사람이에요.
아니에요 — «не являюсь / нет»: 한국 사람이 아니에요.

KZ NOTE
Не переводи слово за словом через русский порядок. В корейском сначала называют страну, затем 사람 — «человек», и только потом ставят связку.

Собери предложение так, как отвечает ученик из Казахстана.

Твоя фраза появится здесь

Подсказка: сначала «я», затем страна, затем человек из страны.
